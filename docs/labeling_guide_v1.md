# SPMCV 场景标注规范 v1

## 标注原则

标注照片中能够直接确认的内容，不按工单步骤、文件夹名、相邻照片或模型预测猜测。整张图无法提供足够证据时选“无法判断”；照片明确不属于这 12 个目标类别时选“其他”。不要把无法判断强行改成一个可训练类别。

每张图按独立照片标注。若动作只在连续照片中可确认，可在备注中记录相邻照片/同工单上下文；需要模型使用这类上下文时，应另外设计并验证多图输入，不能把上下文标签伪装成单图视觉真值。

## 12 类的可见证据

| 标签 | 判定所需证据 | 不足以判定的情况 |
|---|---|---|
| `arrival_plate` | 车头/车辆正面与车牌同框或可明确确认车牌区域 | 仅车身局部、车牌不可读且车辆正面关系不明 |
| `license_vin` | 行驶证版式或证件字段可见，能确认是行驶证 VIN 页 | 其他证件、纸张或无法辨认的局部文字 |
| `frame_vin` | 车架/车辆上的铭牌、VIN 标签或打刻区域可见 | 只有车辆零部件，铭牌/VIN 不在画面中 |
| `odometer` | 仪表盘里程读数区域可见 | 其他仪表、屏幕反光或数字无法辨认 |
| `bridge_drain` | 桥壳/驱动桥油腔位置可确认，且排油口、油流、接油容器或放油操作能支持“放油” | 只有底盘/桥壳，动作和部件位置不清；仅因工单归在桥放油步骤 |
| `bridge_fill` | 桥壳/驱动桥加油口可确认，且加油管、油壶、注油动作等支持“加油” | 只有桥壳或工具，无法确认目标位置/加注动作 |
| `tire_drain` | 轮边/轮端油腔可确认，且排油口、油流或接油过程支持“放油” | 只有车轮/轮胎或底盘环境，油腔与动作不清 |
| `tire_fill` | 轮边/轮端油腔可确认，且加油口/加注工具和加注过程可见 | 只有车轮、工具或油壶，无法确认目标部位和动作 |
| `filter_has` | 目标滤芯位置可见，滤芯本体已安装/存在，或拆下的滤芯能与该位置明确对应 | 仅看到手、机油滤芯外壳或相邻维修动作，无法确认滤芯状态 |
| `filter_none` | 目标滤芯安装位置可见，并能确认滤芯缺失/未安装 | 位置被遮挡、画面太暗或只看到已拆下的零件 |
| `service_front` | 服务单首页/首张表单及 VIN/车辆信息区域可确认 | 其他单据或无法看出表单页次 |
| `service_sign` | 服务单末页/签字盖章区域可见，客户签字或服务站印章字段可确认 | 仅有签字/印章但无法确认服务单或末页区域 |

## 仲裁与训练集规则

- 目录类别和 OOF 预测均为待核对线索，不是人工真值。
- 高置信错误、跨类相似部件、同一工单内连续视角不一致的样本优先复核。
- “无法判断”和“其他”保留审核状态与原因，不计入 12 类分类训练；由数据负责人决定是否扩展任务或类别。
- 对所有类别记录证据状态：`visible`、`partial`、`not_visible`、`unclear` 或 `not_applicable`；动作证据记录 `drain`、`fill`、`none`、`unclear` 或 `not_applicable`。工作台会把这些字段、复核备注与类别一起保存；版本 v1 暂不把这些属性自动写入旧分类训练标签。
- 每次改标保留原标签、仲裁标签、标注人、模型版本、taxonomy 版本、时间和备注。抽样复核需按工单分组，不能把同一工单图片分到训练集和验收集两边。

## 复核优先顺序

1. `bridge_drain ↔ filter_has`、`filter_has ↔ bridge_fill`、`filter_has ↔ bridge_drain`：先确认画面是否真的包含目标部件和动作证据。
2. `bridge_drain ↔ bridge_fill`、`tire_drain ↔ tire_fill`：动作标签必须有放出/注入证据；静态部件照选择“无法判断”。
3. `filter_has ↔ filter_none`：必须看到滤芯位置和状态，不能仅凭工单步骤推断。
4. 新门店/新机型/新拍摄条件样本：检查分布漂移并补充代表性视角。
